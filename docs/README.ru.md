# Tinker Bell — беспроводной дверной звонок

Tinker Bell — автономная система дверного звонка
на базе ESP32, CC1101 и Linux.

Работает локально, без интернета и облачных сервисов.

## Принцип работы

1. Кнопка передаёт радиосигнал 433 МГц.
2. CC1101 принимает сигнал.
3. ESP32 декодирует идентификатор кнопки.
4. ESP32 отправляет DOORBELL через USB.
5. Python выбирает случайный WAV-файл.
6. Linux воспроизводит звук через колонку.

## Возможности

- Поддержка совместимых кнопок EV1527
- Случайное воспроизведение звуков
- Собственная библиотека WAV
- Защита от повторных срабатываний
- Контроль связи с ESP32
- Автоматическое переподключение
- Автозапуск через systemd
- Работа без интернета

## Оборудование

- ESP32 ESP-WROOM-32
- Приёмник CC1101 с антенной
- Беспроводная кнопка 433 МГц
- Кабель USB с передачей данных
- Linux-компьютер
- Колонка или саундбар

Проверенная кнопка: Spreest B100-DB.

## Программное обеспечение

- Arduino CLI — компиляция и прошивка ESP32
- SmartRC CC1101 — управление радиомодулем
- Python 3 — обработка событий
- pyserial — получение данных через USB
- ALSA / aplay — воспроизведение звука
- systemd — работа в фоновом режиме

## Настройка кнопки

Скопируй button_config.example.h
в button_config.h.

Укажи собственный 24-битный код кнопки.

Личная конфигурация исключена из Git.

## Настройка звуков

Создай папку с WAV-файлами.

Путь задаётся через переменную окружения:

    TINKER_BELL_SOUND_DIR

Звуки выбираются случайным образом.
Оригинальные аудиофайлы в репозиторий не входят.

## Безопасность

EV1527 передаёт фиксированный код, который
может быть перехвачен и воспроизведён.

Поэтому система предназначена для уведомлений,
а не для управления дверными замками.
